4. Navigate to your home directory. Create a file named "dog.txt". Using the "echo" command, write the name of your favorite movie into the file.
cd ~
nano dog.txt
echo "Avatar II" > dog.txt

5. 	Edit the file: Using the vim editor, add the names of 4 main characters to the file, each on a new line.
sudo apt install vim
vim dog.txt
i
Quarritch
Avatar
Avatar's wife
Avatar's son
:wq

6. Read the file: Output the contents of the file using the "cat" command.
cat dog.txt

7.  Manage files: Rename the file from "dog.txt" to "cat.txt". 
mv dog.txt cat.txt

Create a new directory named "animals". 
mkdir animals
ls -ld animals
Move "cat.txt" into "animals".
mv cat.txt ./animals/

8. Pathing practice: While inside the "animals" directory, output the contents of "cat.txt" using a relative path (this method of referencing a file is often called "dot notation" or "via dot").
cd animals
cat cat.txt
cat ../animals/cat.txt

9. Navigate to the root directory. 
cd /
Output the contents of "cat.txt" using both the absolute and relative paths.
cat ~/animals/cat.txt
cat /home/vboxuser/animals/cat.txt
